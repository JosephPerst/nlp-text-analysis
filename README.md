# NLP Text Analysis

Natural Language Processing projects using state-of-the-art transformer models for text classification and analysis.

## Projects

| Notebook | Description |
|----------|-------------|
| `NLP FINAL PROJECT CODE.ipynb` | Final NLP project implementation |
| `Big Bird NEWEST HIGH ACC.ipynb` | Text classification using BigBird/Longformer with high accuracy |
| `Newest DistilBERT model With Extra Classification.ipynb` | DistilBERT-based classification model |
| `Long Text Analysis Code.ipynb` | Analysis pipeline for long-form text documents |
| `Updated Using DistBERT.ipynb` | Updated DistilBERT implementation |

## Models Used
- **Longformer** - Handles long documents (up to 4096 tokens)
- **BigBird** - Sparse attention for long sequences
- **DistilBERT** - Efficient BERT distillation

## Tech Stack
- Python 3.8+
- TensorFlow / Keras
- Hugging Face Transformers
- NLTK
- scikit-learn
- pandas / numpy

## Installation

```bash
pip install -r requirements.txt
```

## Usage

Open any notebook in Jupyter:
```bash
jupyter notebook
```
